# DH Manus Operating System

## Purpose

This repository contains the **DH Manus Operating System**: the operating-model, living-documentation, and reusable workflow assets developed to turn a governed knowledge library into a mission-based venture and product-delivery system.

Its central concept is a **Mission Compiler**. An approved mission instruction should assemble only the relevant context, create a traceable work graph, delegate bounded specialist work, produce decision-ready artifacts, and stop at named human approval gates. It is not an unrestricted autonomous-agent framework.

## Relationship to the Human Blockchain Operating System

The private [Human Blockchain Operating System](https://github.com/donaldhaight/human-blockchain-operating-system) is the upstream knowledge bundle and domain context for this work. This repository does **not** mirror, replace, or alter that upstream bundle. Instead, it contains the operating mechanisms that can use a curated Human Blockchain knowledge library—or another approved knowledge library—as governed input.

| Repository | Role |
|---|---|
| `human-blockchain-operating-system` | Upstream domain knowledge, thesis, institutional memory, and Human Blockchain context. |
| `dh-manus-operating-system` | Operating layer: mission compilation, evidence handling, decision gates, living documentation, and reusable research/platform-evolution workflows. |

## Operating Principles

1. **Evidence before assertion.** Distinguish observed facts, reports, inferences, assumptions, and decisions.
2. **Human authority at consequential gates.** Agents may prepare, analyze, draft, test, and recommend; designated humans approve external commitments, capital, constitutional changes, production releases, and material risk acceptance.
3. **Independent design.** Study public behavior and customer outcomes without reusing protected expression, source code, credentials, private data, or access-controlled behavior.
4. **Living documentation, not silent revision.** Maintain versioned artifacts with stable IDs, named owners, evidence links, decision links, and supersession records.
5. **Controlled improvement.** Promote a change only through evidence, a candidate delta, evaluation, named approval, versioned update, and monitoring.

## Current Scope

The `main` branch contains the first operating-system baseline, preserved by the `v0.1.0-session-baseline` tag. The [`experiment/ultimate-stack`](https://github.com/donaldhaight/dh-manus-operating-system/tree/experiment/ultimate-stack) branch contains an architecture and roadmap for a secure multi-agent control plane. The experiment has **not** provisioned a persistent runtime, enabled external integrations, or granted authority to perform external actions.

## Provenance and Handling

The `docs/research/` directory includes raw benchmark outputs and directly validated research notes produced in the initiating session. Treat recommendations as operating-model design inputs, not as legal, financial, or regulatory advice. Preserve citations and revisit time-sensitive sources when decisions depend on them.
